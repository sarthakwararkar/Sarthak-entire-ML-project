Model Inputs

The prediction form supports these student attributes:

  • Gender
  • Race / Ethnicity
  • Parental Education
  • Lunch Type
  • Test Preparation
  • Reading Score
  • Writing Score
How it works

A preprocessor and trained regression model work together to transform submitted values and output an estimated student performance score.

The app is built for fast experimentation with student data and clean model-driven predictions.
